# Phishing URL Detector

## About the Project

A Python-based tool that analyzes URLs for common phishing indicators
and calculates a risk score to identify potentially suspicious URLs.

## Features

- HTTPS verification
- URL length analysis
- Suspicious '@' symbol detection
- IP address detection
- Suspicious keyword detection
- Risk score calculation
- Low, Medium, and High risk classification

## Technologies Used

- Python
- Regular Expressions

## How It Works

The user enters a URL, and the tool checks it for multiple
phishing-related indicators. Based on the detected indicators,
a risk score is calculated and the URL is classified by risk level.
